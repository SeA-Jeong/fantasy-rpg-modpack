## **2. 추가로 수정하고 싶은 세 가지**

### **첫 번째: 투자 조건만으로는 찍먹 빌드를 완전히 막지 못합니다.**

5·10·15·20SP 선행 조건은 좋은 해결책입니다.

다만 이전 노드에 투자한 포인트를 요구하더라도, 스킬 1랭크의 효과가 지나치게 강하면 플레이어는 여전히 여러 노드에 1SP씩 투자하려고 할 것입니다.

그래서 **스킬 랭크가 올라갈수록 추가적인 기능이 개방되는 구조**를 추천합니다.

예를 들어 전사의 마력 베기를 다음처럼 설정합니다.

| 랭크 | 효과                  |
| -- | ------------------- |
| 1  | 주문력 100% 피해         |
| 2  | 주문력 120% 피해         |
| 3  | 주문력 135% 피해 + 마력 표식 |
| 4  | 주문력 155% 피해         |
| 5  | 주문력 175% 피해 + 표식 폭발 |

이러면 첫 1SP를 투자해 기술을 습득하는 것과 5SP까지 투자해 완성하는 것 사이에 확실한 차이가 생깁니다.

특히 핵심 패시브는 1랭크만으로 전체 효과가 발동하지 않도록 조정하는 것이 좋습니다.

### **두 번째: 혼합 스킬의 계수에는 아직 허점이 있습니다.**

제안받은 공식은 다음과 같습니다.

\\[ D\_{\text{혼합}}=0.9C(A+M) \\]

여기서 A+M=B이므로 장비의 공격력과 주문력 비율에 관계없이 혼합 스킬 피해가 같습니다.

예를 들어 C=2, B=100이라고 가정하겠습니다.

| 장비 성향 | 공격력 A | 주문력 M | 순수 물리 스킬 | 혼합 스킬 |
| ----- | ----- | ----- | -------- | ----- |
| 물리 특화 | 100   | 0     | 200      | 180   |
| 균형형   | 50    | 50    | 100      | 180   |
| 주문 특화 | 0     | 100   | 0        | 180   |

이 방식은 혼합 스킬이 과도하게 강해지는 문제를 줄이지만, 반대로 **혼합 스킬만 사용할 경우 균형형 장비를 착용할 이유가 없어지는 문제**가 있습니다.

저는 혼합 스킬 자체는 안정적인 피해를 유지하면서 공격력과 주문력이 균형에 가까울수록 작은 추가 효과를 제공하는 것을 추천합니다.

예를 들어 균형형 장비에 5% 정도의 혼합 스킬 보너스를 주되, 물리·마법 특화 장비의 최대 화력을 넘어가지 않도록 합니다.

다만 보너스를 반드시 피해량으로 줄 필요는 없습니다. 전사의 룬 검격이라면 균형형 장비에서 추가 마력 충격파가 발생하는 식으로 차별화해도 됩니다.

### **세 번째: 수호 스킬은 방어 성공에만 의존하면 안 됩니다.**

제안받은 반격형 스킬은 매우 좋은 방향입니다.

하지만 보스의 공격을 막아야만 반격이 발동하는 구조라면, 공격 빈도가 낮은 보스나 원거리 공격을 주력으로 사용하는 보스에게 불리할 수 있습니다.

그래서 수호 방향에 두 가지 공격 경로를 제공하면 좋겠습니다.

- **반응형 공격:** 방어 성공 시 강력한 반격을 발동합니다.
- **능동형 공격:** 방어 성공 여부와 관계없이 사용 가능한 공격 기술을 제공합니다.

수호 특화 캐릭터는 순수 공격형보다 피해량이 낮더라도 장시간 안정적으로 공격할 수 있어야 합니다.

그리고 제안된 것처럼 단순 DPS뿐 아니라 보스 처치 성공률, 실제 소요 시간, 소비 아이템 사용량을 함께 평가해야 합니다.

## **3. 직업 코어 자원은 가장 마음에 드는 개선점입니다.**

이 부분은 4방향 스킬트리의 중심 시스템으로 정식 채택하는 것을 추천합니다.

## **직업 코어 + 4방향 성장 구조**

모든 직업은 동일한 방향을 사용하되 코어 자원과 스킬이 다름

**주문력**

**공격력**

직업 코어 자원

**기교**

**수호**

예를 들어 전사와 기사가 똑같이 수호 방향에 20SP를 투자했다고 가정하겠습니다.

**전사**는 적의 공격을 견디고 전투 기세를 축적하여 강력한 검격을 사용합니다. **기사**는 공격을 정확하게 방어해 반격 자원을 축적하고, 이를 소비해 강력한 방패·창 연계 공격을 사용합니다.

같은 수호 빌드인데도 플레이 방식이 달라집니다.

| 직업   | 코어 자원 | 축적 방식              |
| ---- | ----- | ------------------ |
| 전사   | 전투 기세 | 공격 적중, 전투 지속       |
| 기사   | 결의    | 방어 성공, 반격, 일부 창 공격 |
| 도적   | 연계 표식 | 연속 적중, 급소 타격       |
| 궁수   | 집중    | 조준 유지, 정확한 공격      |
| 마법사  | 마나    | 시간 회복, 주문 연계       |
| 전투사제 | 신성력   | 공격 적중, 정화, 방어      |

각 직업의 네 방향은 이 자원을 생성·소비·강화하는 방법을 변화시킵니다.

특히 **전사가 주문력 방향에 투자하더라도 별도로 마나를 도입하지 않고, 전투 기세를 소비해 마법 검술을 사용**할 수 있도록 설계하면 직업 정체성이 더욱 확실해집니다.

## **6. 추가로 제안하고 싶은 것**

여기서 한 가지 더 결정하면 좋겠습니다.

**스킬 포인트와 기본 능력치 포인트를 분리할 것인지**입니다.

지금은 공격력 방향에 포인트를 투자한다는 것이 공격력이라는 능력치 자체를 올리는 것인지, 공격력 계수 기반 스킬을 배우는 것인지 명확하게 구분되어 있지 않습니다.

저는 우선 다음 두 시스템을 분리할 것을 추천합니다.

- **스킬 포인트(SP):** 4방향 스킬트리의 기술을 습득하거나 강화하는 데 사용
- **능력치:** 레벨, 장비, 패시브 등으로 증가하는 공격력·주문력·방어력 등의 실제 수치

이렇게 하면 공격력 방향에 투자했다고 물리 공격력이 자동으로 증가하는 것이 아니라, 물리 공격 기술이나 공격력 패시브를 습득한 만큼 성능이 높아집니다.

그 결과 마검사형 전사가 공격력 방향의 기술과 주문력 방향의 기술을 조합하는 것도 자연스럽게 구현할 수 있습니다.

별도의 능력치 포인트를 추가할지는 이후에 결정해도 됩니다. 지금 단계에서는 스킬 포인트와 장비 성향만으로 충분한 빌드 자유도를 제공할 수 있습니다.

**결론적으로, 제시된 의견은 v0.3의 구조를 바꾸기보다 완성도를 높이는 수정안입니다.** 저는 대부분 채택하되, 혼합 계수와 랭크별 성장 효과, 수호의 능동형 공격 수단을 추가로 보완하여 **v0.4를 직업 시스템의 기준 설계**로 정하는 것이 가장 좋다고 생각합니다.
