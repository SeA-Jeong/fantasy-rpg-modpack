# **마인크래프트 판타지 RPG — 자유 스킬트리 시스템 설계 v0.2**

기존의 **기본 직업 6종은 유지하되, 1차 전직을 폐지하고 직업별 자유 스킬트리**를 적용하겠습니다.

예를 들어 전사는 검투사 또는 광전사 중 하나를 선택하는 방식이 아닙니다. 검술에 집중하면서 광전사의 공격력 증가 효과를 배우거나, 방어구 파괴 기술을 조합하여 자신만의 전투 스타일을 완성할 수 있습니다.

모든 직업은 단독 전투가 가능하며, 채굴·제작 등 생활 스킬은 전투 스킬트리에 포함하지 않습니다.

이 구조가 자유 스킬트리를 의미 있게 만듭니다. 한 트리를 완성할지, 여러 트리를 고르게 육성할지 선택해야 합니다.

- 상급 노드: Lv.40 이상, 같은 트리에 15SP 투자
- 궁극기: Lv.40 이상, 같은 트리에 18SP 투자

## **7. 스킬의 실제 수치 밸런스**

자유 스킬트리는 조합에 따라 피해량이 급격하게 증가할 수 있으므로, 초기에는 효과의 증가 폭을 제한하는 것이 좋습니다.

다음은 각 직업의 기본 공격 1회를 100%로 정규화한 예시입니다.

| 스킬 유형   | 초기 수치 예시    | 성장 방식                |
| ------- | ----------- | -------------------- |
| 기본 공격   | 100%        | 무기·레벨의 영향            |
| 일반 액티브  | 130\~180%   | 레벨당 스킬 피해 +10\~15%p  |
| 강력한 액티브 | 200\~280%   | 피해 또는 부가효과 강화        |
| 궁극기     | 450\~650%   | 획득 시 완성형, 긴 재사용 대기시간 |
| 공격력 패시브 | 최대 +10%     | 5SP 투자 기준            |
| 방어 패시브  | 최대 +10\~12% | 5SP 투자 기준            |
| 회복 패시브  | 전투 조건부 회복   | 연속 회복량에 상한 적용        |

퍼센트 피해는 무기 공격력을 기준으로 산정하며, 방어구와 적의 피해 감소 효과를 적용한 최종 피해는 별도로 계산합니다.

### **직업 간 균형을 위한 규칙**

- 같은 장비 등급과 레벨의 단일 보스전에서 직업 간 장기 평균 화력 차이는 가급적 ±10\~15% 이내를 목표로 합니다.
- 기사와 전투사제는 낮은 순간 화력을 반격이나 지속 전투 능력으로 보완합니다.
- 궁수와 마법사는 거리 유지라는 장점이 있지만, 모든 보스를 안전한 위치에서 일방적으로 공격하지 못하도록 합니다.
- 보스에게 군중 제어가 완전히 무효화되지 않도록 기절 대신 경직 게이지 감소 등의 대체 효과를 적용할 수 있습니다.
- 특정 몬스터 종류에 특화된 스킬은 일반 적에게도 기본 효과가 있어야 합니다.

기존에 설정한 12장 최종 보스 HP 1,250을 유지한다면, 2\~4분 내 처치를 위해 실제 보스 체력 감소 속도는 대략 초당 5.2\~10.4HP를 목표로 잡을 수 있습니다. 이를 기준으로 최종 장비 공격력과 스킬 계수를 조정하면 됩니다.

- Lv.1\~20: 스킬 초기화 무료
- Lv.21\~60: 마을의 직업 교관에게 게임 내 화폐를 지불하여 초기화
- Lv.20: 스킬 빌드 프리셋 2개 개방
- Lv.40: 스킬 빌드 프리셋 3개까지 확장
- 던전 및 보스 전투 중에는 초기화와 빌드 교체 불가
- 빌드 변경은 마을이나 안전 지역에서 가능

스킬 초기화 비용은 희귀 광물이 아닌 일반 게임 화폐로 지불하도록 하겠습니다. 초기화 때문에 채굴이나 특정 몬스터 파밍을 강제로 반복하는 상황을 피하기 위해서입니다.

## **9. 네더 진입 이후의 직업 성장**

오버월드에서 완성한 스킬트리를 네더에서 다시 처음부터 육성하게 할 필요는 없습니다.

네더에서는 **기존 스킬트리를 유지한 채 차원 각성 스킬을 추가**하는 것을 추천합니다.

예를 들어 전사라면 다음과 같이 확장할 수 있습니다.

| 오버월드 기술 | 네더 각성 예시                 |
| ------- | ------------------------ |
| 연속베기    | 연속베기 마지막 공격에 검기 추가       |
| 광폭화     | 광폭화 중 공격 성공 시 지속시간 일부 연장 |
| 방어구 파괴  | 마계 생명체의 마법 방어도 일부 감소     |
| 검술 궁극기  | 추가 검기와 특수 연계 공격 개방       |

네더의 신규 광물은 각성 스킬의 원활한 사용을 보조하는 장비를 만드는 데 활용하고, 각성 스킬 자체는 네더 스토리와 전투 진행으로 개방하도록 설계하는 것이 기존 재료 수급 방향과도 맞습니다.

## **10. 실제 구현 단계에서의 권장 범위**

6개 직업에 3개 트리, 트리당 7개 노드를 적용하면 **총 126개 스킬 노드**가 필요합니다. 상당한 작업량이므로 처음부터 모든 노드를 구현하기보다는 단계적으로 진행하는 것이 좋습니다.

| 개발 단계 | 구현 내용                     |
| ----- | ------------------------- |
| 1단계   | 전사 1개 직업, 검술·광전·파쇄 3개 트리  |
| 2단계   | 스킬 포인트, 선행 조건, 재분배, 슬롯 UI |
| 3단계   | 나머지 5개 직업의 기본 전투 기술       |
| 4단계   | 각 직업의 중급·상급 스킬 및 궁극기      |
| 5단계   | 보스전 검증, 직업별 화력·생존력 조정     |
| 6단계   | 네더 각성 시스템                 |

### **최종 추천 방향**

현재 프로젝트에서 확정할 만한 기준은 **6개 기본 전투 직업, 직업당 3개 자유 스킬트리, 오버월드 66SP, 액티브 4개와 궁극기 1개 장착**입니다.

다만 가장 중요한 추가 설계 사항이 하나 있습니다. **마법사나 궁수에게도 근접 무기를 사용할 자유를 허용할 것인지**, 아니면 직업별 주력 무기를 고정할 것인지입니다. 이 결정에 따라 스킬트리를 무기 중심으로 설계할지, 직업 능력 중심으로 설계할지가 크게 달라집니다.

현재 구조에서는 직업별 주력 무기 계열은 유지하되, 동일 직업 내부에서 여러 무기를 자유롭게 선택할 수 있도록 하는 방식을 우선 추천합니다.
