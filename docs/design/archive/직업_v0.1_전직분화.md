# **3. 직업 간 전투 밸런스**

직업마다 특색이 있어도 특정 직업이 모든 콘텐츠에서 무조건 유리하지 않아야 합니다.

다음은 실제 수치가 아니라 **동일 레벨·동급 장비를 착용했을 때의 상대적 전투 성능 목표**입니다.

| 직업   | 공격력 | 생존력 | 기동력 |
| ---- | --- | --- | --- |
| 전사   |     |     |     |
| 기사   |     |     |     |
| 도적   |     |     |     |
| 궁수   |     |     |     |
| 마법사  |     |     |     |
| 전투사제 |     |     |     |

5점 척도. 공격력은 해당 직업이 유리한 전투 상황을 기준으로 한 상대적 평가입니다.

특히 기사와 전투사제는 공격력이 낮다는 이유로 보스전에서 지나치게 불리하면 안 됩니다. 따라서 낮은 순간 화력을 높은 전투 지속력, 반격 피해, 안정적인 공격 기회로 보완합니다.

**모든 직업이 혼자서 보스를 공략할 수 있도록 설계하는 것이 최우선**입니다. 파티 플레이는 선택적인 협력 콘텐츠로 두는 것을 추천합니다.

# **4. 직업별 전용 자원과 무기**

마인크래프트의 조작 체계를 지나치게 복잡하게 만들지 않으면서 직업 특징을 살리는 것이 중요합니다.

| 직업   | 주력 무기      | 핵심 전투 시스템     |
| ---- | ---------- | ------------- |
| 전사   | 한손검·양손검·도끼 | 공격 연계, 전투 기세  |
| 기사   | 검·방패·창     | 방어 성공 후 반격 강화 |
| 도적   | 단검·쌍검      | 연속 타격, 표식 폭발  |
| 궁수   | 활·석궁       | 조준 집중, 약점 공격  |
| 마법사  | 지팡이·마도서    | 마나, 원소 연계     |
| 전투사제 | 철퇴·전투 지팡이  | 공격을 통한 신성력 축적 |

기본 공격과 스킬을 공통 구조로 만들고, 직업마다 전용 패시브와 특수 능력을 넣는 편이 구현과 밸런스 관리에 유리합니다.

# **5. 광물과 직업의 관계**

앞서 정한 **퀘스트와 몬스터 사냥 중심 재료 수급 시스템**도 직업에 맞춰 구성할 수 있습니다.

다만 특정 직업이 특정 광물만 사용하도록 강제하지는 않는 것을 권장합니다.

| 장비 재료  | 활용도가 높은 직업    |
| ------ | ------------- |
| 철·강철   | 전사, 기사        |
| 은      | 전투사제, 도적      |
| 미스릴    | 도적, 궁수, 마법사   |
| 다이아몬드  | 기사, 전사        |
| 아다만타이트 | 기사, 전사, 전투사제  |
| 오리하르콘  | 모든 직업의 최상위 장비 |

예를 들어 미스릴을 얻은 플레이어가 전사라면 가벼운 미스릴 검을 제작할 수 있고, 마법사라면 미스릴 지팡이를 제작할 수 있습니다.

따라서 동일한 몬스터와 퀘스트를 진행해도 직업에 따라 필요한 장비를 선택해 제작할 수 있습니다.

## **6. 추가로 결정하면 좋은 사항**

지금 단계에서는 직업을 더 많이 추가하기보다는 **기본 6종과 전직 12종**으로 출발하는 것을 추천합니다. 초기에 직업을 지나치게 늘리면 스킬, 무기, 장비와 보스 패턴의 밸런스 작업량이 크게 증가하기 때문입니다.

다만 실제 전직 시스템을 확정하기 전에 선택해야 할 중요한 방향이 있습니다.

직업 성장 방식 선택

**A. 전직 분화형 (추천)**

전사 → 검투사 또는 광전사. 각 전직이 고유 스킬을 사용하는 방식

**B. 자유 스킬트리형**

전사로 시작하되 스킬 선택에 따라 검투사형·광전사형으로 성장하는 방식

**C. 고정 직업 성장형**

처음부터 검투사, 광전사 등 세부 직업을 선택하고 해당 직업을 끝까지 육성하는 방식

선택한 방식으로 구체화하기&#x20;

저는 **A안 전직 분화형**이 오버월드 12장 진행과 네더 2막 진입이라는 구조에 가장 잘 맞는다고 봅니다. 20레벨의 전직과 40레벨의 상급 기술, 네더의 2차 각성을 각각 중요한 성장 목표로 만들 수 있기 때문입니다.
