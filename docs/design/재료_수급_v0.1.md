그렇다면 기존 초안의 성장 구조를 변경하는 것이 좋겠습니다. **마인크래프트의 채굴과 건축은 자유롭게 즐기는 콘텐츠로 남기고, RPG 성장의 중심은 퀘스트·몬스터 사냥·던전 공략으로 옮기는 방식**입니다.

특히 중요한 조건은 **광질을 한 번도 하지 않은 플레이어도 오버월드 12장을 모두 클리어하고 네더에 진입할 수 있어야 한다**는 것입니다.

## **1. 재료 수급 시스템 변경**

기존의 `광물 채굴 → 장비 제작 → 보스 공략` 구조를 다음과 같이 수정하겠습니다.

지역 진입 및 메인 퀘스트 수락

새로운 몬스터와 지역 개방

**몬스터 사냥**

광물 파편·제작 재료·강화석

**퀘스트 완료**

확정 장비 재료·경험치·화폐

**장비 제작 및 강화**

광질 없이 필요 재료 확보 가능

**지역 보스 공략 → 다음 장 개방**

## **2. 재료 획득 경로의 비중**

다음 비율은 전체 플레이어가 얻는 재료의 강제 배분이 아니라, 개발자가 보상을 설계할 때 참고할 **목표 공급 비중**입니다.

**퀘스트 완료 보상**

45%

**몬스터 처치 및 반복 사냥**

30%

**던전 및 보스 보상**

20%

**채굴 및 기타 생활 콘텐츠**

5%

채굴 5%는 최대 획득량 제한이 아닙니다. 플레이어가 채굴을 좋아한다면 자유롭게 더 얻을 수 있습니다. 다만 **채굴하지 않았다는 이유로 성장에 불이익을 주지 않는 것**이 핵심입니다.

## **3. 광물별 신규 획득 시스템**

광물 자체는 기존 마인크래프트와 마찬가지로 월드에 생성하지만, 몬스터나 퀘스트를 통해서도 획득하도록 합니다.

| 광물     | 첫 등장  | 주요 수급 방법           |
| ------ | ----- | ------------------ |
| 구리     | 1\~2장 | 야생 고블린, 기본 퀘스트     |
| 철      | 2\~3장 | 무장 고블린, 산적, 언데드 병사 |
| 은      | 4장    | 습지 마수, 언데드, 정화 퀘스트 |
| 강철     | 5장    | 중장갑 몬스터, 고대 병사     |
| 미스릴    | 7장    | 정령 몬스터, 마법 생명체     |
| 다이아몬드  | 8장    | 심층 마수, 지하 던전       |
| 아다만타이트 | 9장    | 설산 거인, 갑각형 마수      |
| 오리하르콘  | 11장   | 고룡의 권속, 용맥 마수      |

여기서 중요한 것은 몬스터가 반드시 광석 원석을 떨어뜨릴 필요는 없다는 것입니다.

예를 들어 정령 몬스터는 `미스릴 파편`, 용맥 마수는 `오리하르콘 결정`, 중장갑 언데드는 `강철 파편`을 드롭하게 구성할 수 있습니다.

제작소에서 일정 수량을 모아 주괴로 가공할 수 있게 하면 자연스럽습니다.

반면 몬스터를 추가로 사냥한 플레이어는 재료를 더 확보해 다른 무기나 방어구를 제작하거나, 장비 강화에 투자할 수 있습니다.

즉, **퀘스트는 필수 성장 보장, 몬스터 사냥은 추가 성장과 선택의 자유**를 담당합니다.

## **5. 몬스터 드롭 밸런스**

몬스터가 광물을 드롭하게 설정하면 전투가 중요한 파밍 수단이 됩니다. 다만 낮은 확률에만 의존하면 반복 사냥이 지나치게 길어지므로 일반 재료와 희귀 재료를 구분하겠습니다.

| 몬스터 등급 | 일반 재료   | 희귀 재료    | 역할          |
| ------ | ------- | -------- | ----------- |
| 일반     | 100%    | 5\~10%   | 기본 재료 수급    |
| 강화 일반  | 100%    | 10\~15%  | 효율적인 반복 사냥  |
| 정예     | 100%    | 20\~30%  | 고급 재료 수급    |
| 필드 보스  | 확정 대량   | 확정 1개 이상 | 반복 파밍 대상    |
| 챕터 보스  | 첫 처치 확정 | 핵심 재료 확정 | 다음 성장 단계 해금 |

여기서 일반 재료 100%는 매 처치마다 정해진 수량의 재료를 지급한다는 의미입니다. 희귀 재료의 드롭 확률은 실제 플레이 시간에 따라 조정할 초기값입니다.

핵심 장비 제작에 필요한 물품은 희귀 확률 드롭에만 맡기지 않고 퀘스트나 교환 상점으로 보완해야 합니다.

## **7. 기존 초안에서 변경할 사항**

| 기존 설계              | 변경 후                  |
| ------------------ | --------------------- |
| 채굴로 일반 장비 재료 확보    | 퀘스트·전투로 일반 장비 재료 확보   |
| 광물별 곡괭이 등급으로 진행 제한 | 스토리와 장비 제작법으로 진행 제한   |
| 희귀 광물을 채굴해야 장비 제작  | 몬스터 드롭과 퀘스트로 제작 가능    |
| 광산 탐험이 주요 성장 활동    | 광산은 선택형 탐험 콘텐츠        |
| 일반 광물 채굴과 제련 중심    | 몬스터 소재 가공·장비 제작 중심    |
| 보스 재료로 특수 장비 제작    | 보스 재료로 장비 각성·다음 단계 개방 |

### **추가로 권장하는 설계 원칙**

**장비 제작은 필수, 채굴은 선택, 몬스터 파밍은 권장**하는 구조입니다.

이렇게 만들면 RPG 중심으로 플레이하는 사람은 퀘스트를 따라가면서 성장하고, 건축이나 채굴을 좋아하는 사람은 자유롭게 마인크래프트 본연의 콘텐츠를 즐길 수 있습니다.

한 가지 더 추천하고 싶은 것은 **마인크래프트의 광물과 몬스터 전용 재료를 분리하는 방식**입니다.

예를 들어 미스릴은 채굴하거나 몬스터를 잡아서 확보할 수 있는 공통 재료이고, 정령의 심장이나 고룡의 비늘은 전투로만 획득하는 재료로 만들 수 있습니다. 그러면 광물의 가치를 유지하면서도 전투 중심 판타지 RPG라는 특징이 확실해집니다.

다음으로는 **12개 장 각각에서 어떤 몬스터가 어떤 재료를 얼마나 떨어뜨리는지, 퀘스트 보상으로 장비 몇 개를 제작할 수 있는지**까지 설정하면 전체 오버월드 성장 체계가 상당히 구체화됩니다.
