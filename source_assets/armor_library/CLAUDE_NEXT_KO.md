# Claude 적용 지시 — AI 제작 장비 폐기, 오픈소스 기반 전면 전환

이 ZIP은 새 오픈소스 장비 리소스 수집/배분 **기초 라이브러리**다. ZIP 자체에 다른 제작자의 자산이 들어있다고 가정하지 말 것.

1. `README_KO.md`, `01_sources.csv`, `04_240_slots.csv`를 읽고 진행한다.
2. `python tools/verify_catalog.py` 실행. 실패하면 코드/매니페스트부터 수정.
3. 인터넷 연결된 개발 환경에서 `python tools/fetch_upstream.py --source primary` 실행.
4. 원본 확보 후 `python tools/build_staging.py`로 임시 리소스 스테이징. 원본은 불변 유지.
5. FantasyRPG 실제 NeoForge/Fabric/Forge 버전, GitHub 프로젝트 구조, 기존 Item/Armor renderer/아이템 ID 목록 확보. 별도 모드 ID 생성이나 기존 기능 덮어쓰기 금지.
6. **먼저 3종** 기사 T01, 마법사 T05, 도적 T10의 기존 자체 생성 장비 리소스를 비활성화하고, 원본에서 선택한 구조로 대체. 기존 리소스는 백업하되 새로운 배포 패키지에 실수로 포함하지 않는다.
7. `.bbmodel`을 열어 부위별 4슬롯 재배치/피벗/UV 수정. More Armor의 아이콘/착용 레이어는 2D 소재로만 사용하고 3D 모델이라고 주장하지 말 것.
8. 1~7급 오버월드, 8~10급 네더 세계관. 같은 직업도 T01~T10의 구조적 차이 필수; 동일 모델의 단순 색변경은 신규 개별 3D 모델 수에 미포함.
9. 매 작업 단위마다 아이콘-착용모델 일치, Blockbench 불러오기, 컴파일, 실제 인게임 착용/관통 테스트 결과와 라이선스를 기록.
10. 게임 적용 완료 파일에만 `files_imported=1`, `3d_model_converted=1`, `game_linked=1`, `game_tested=1` 단계별로 기록. 소스 후보만 있다면 0으로 유지.
11. `04_240_slots.csv`를 가장 최신 상태로 유지하고, 미배정 슬롯의 후보 탐색을 계속한다.
12. 크레딧 `LICENSES/`와 출처 매니페스트를 실제 배포물에 포함한다.

중요: 27개 2D 원본 세트 배정은 미술적 후보일 뿐 확정이 아니다. 샘플 검증에서 Minecraft 스타일이 어색하면 사용하지 말고 다른 라이선스 명확한 모델을 탐색한다.
