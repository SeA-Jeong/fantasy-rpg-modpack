# 보스 수치 견본 데이터팩 (magiccity)

이 폴더는 **지금 게임에 들어 있는 기본값을 그대로 담은 견본**입니다. 그대로 켜도 아무것도 바뀌지 않습니다.
보스 수치를 바꾸려면 이 폴더를 복사해 이름을 바꾸고(예: `my_boss_stats`), 숫자만 고친 뒤 월드의 `datapacks/` 폴더에 넣고 `/reload` 하세요.
값은 **새로 등장하는 보스부터** 쓰입니다(싸우는 중인 보스는 그대로).

## 규칙
- 같은 경로·같은 파일 이름이면 덮어씀. 필요 없는 파일은 지워도 됨(지운 파일은 기본값).
- 파일 안에서도 **적힌 항목만** 덮어씀. 빠진 항목은 기본값.
- 범위 밖 값이나 모르는 항목이 있으면 그 파일 전체를 쓰지 않고 서버 로그에 `[보스] ... 읽기 실패` 를 남김.
- 확인: `/magiccity boss stats` (전체), `/magiccity boss stats <키 또는 장 번호>` (값과 그 값을 준 데이터팩 이름)

## 파일
| 경로 | 내용 |
|---|---|
| `data/magiccity/boss_stats/<보스 키>.json` | 챕터 보스 12종 |
| `data/magiccity/boss_stats/_grades.json` | 등급 1~6 보스 기본 공격(`basic`)·체력 배율(`hp_scale`), 값 6개씩 |
| `data/magiccity/field_boss_stats/<키>.json` | 필드보스 10마리 |
| `data/magiccity/boss_entity/<보스 키>.json` | 그 장 보스를 외부 모드 몹으로 바꾸기 |

보스 키: 1 `plague` · 2 `cursedboss` · 3 `parasite` · 4 `frost` · 5 `furnace` · 6 `deep` · 7 `tombboss` · 8 `grimbald` · 9 `skyboss` · 10 `watcher` · 11 `dragon` · 12 `gatekeeper`

## 항목 (허용 범위)
| 항목 | 뜻 | 범위 |
|---|---|---|
| `scale` | 크기 | 0.0625~16 |
| `health` | 최대 체력 | 1~10000 |
| `attack` | 근접 공격(등급 배율의 기준값 — 실제 피해는 그 등급 `basic` 이 되도록 맞춰짐) | 0~200 |
| `armor` | 방어력 | 0~30 |
| `knockback_resistance` | 밀치기 저항 | 0~1 |
| `follow_range` | 추적 거리 | 1~256 |
| `speed` | 이동 속도 (없으면 바탕 몹 그대로) | 0~2 |
| `mount` | 8장 `grimbald` 의 탈것(약탈수) 수치, 위 항목과 같음 | |

## 외부 보스 연결 (`boss_entity`)
| 항목 | 뜻 | 기본 |
|---|---|---|
| `entity` | 몹 id (그 모드가 없으면 기본 보스로 싸움) | 필수 |
| `enabled` | false 면 이 연결을 끔 | true |
| `our_skills` | 우리 기술·부하 소환·광폭화 | false |
| `our_bossbar` | 우리 체력바 | false |
| `grade_scaling` | 진행 등급 배율(공격·체력) | true |
| `anchor_nbt` | 전장 안 보스 자리 블록 좌표(`[I; x, y, z]`)를 넣어 줄 NBT 이름 | 없음 |
| `nbt` | 소환 NBT (SNBT 문자열 또는 JSON 객체) | 없음 |
| `name` | 머리 위 이름표 | 없음 |
